How to use Candela

        
    
          
  1. Open a folder — in Library, click ＋ next to "Folders" and pick a folder of photos (raw files like CR3, ARW, NEF, DNG, RAF or standard images like JPEG, PNG, TIFF, WebP, HEIC). Desktop Chrome / Edge / Opera. It is read only in your browser — nothing is uploaded.
    2. 
          
  2. Cull — step with ← →. Rate 1–5, reject X, pick P, clear U, color 6–9. Filter with the checkboxes on the left.
    3. 
          
  3. Collect — in Library, select photos in the grid and click ＋ in the panel header to start a collection from the selected photos, or ＋ on a collection row to add them to an existing one; the count on the row updates. Click a collection to see only its photos, − in the panel header removes the selected photos from it, × deletes the collection (photos stay). Smart Collections fill themselves from the cull marks: ＋ opens a rule (rating, flag, modified dates), ✎ edits it, and the count grows as you rate. With photos selected, a new rule is bounded to them by default — switch Photos to "Every photo in the catalog" to let it reach everything — and the preview under the form says how many photos it matches before you save.
    4. 
          
  4. Develop — E opens the loupe. Adjust White Balance, Tone, Presence, Tone Curve, Effects, Crop… every edit is live, undoable (Ctrl+Z), and saved with the file. Hold \ for before/after.
    5. 
          
  5. Export — pick a format (JPEG / PNG / TIFF), size and preset, then press Export.
    6.

Candela needs a WebGPU browser

          
Every adjustment runs on the GPU, so this app can't run in the browser you're using right now.

          
    
            
  • Use the latest Google Chrome, Microsoft Edge, or Opera on a desktop computer.
    • 
            
  • Open the site over HTTPS or localhost.
    • 
            
  • Safari, Firefox, and mobile browsers aren't supported yet.
